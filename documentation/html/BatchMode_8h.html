Executes the review assignment and risk analysis in batch mode.

Loads the data from the provided input file, runs the assignment algorithm (and risk analysis, if enabled by the input configuration), and writes the results directly to the specified output file.

Parameters
inputFilenameThe path to the input configuration CSV file.
riskOutputFilenameThe path to the output file to write results and risk analysis.
Returns
0 on successful execution, 1 on failure (e.g., file not found).
Note
Time complexity: Dominated by the execution of the assignment and risk analysis pipelines, bounded by O(R * V * E²) in the worst-case scenario.
