Detailed Description

Interactive terminal menu for the conference organization tool.

Provides a user-friendly CLI to load datasets, inspect data, and execute the review assignment and risk analysis algorithms step-by-step.

void runInteractiveMode ( )

Launches the interactive menu loop.

Displays a text-based interface allowing the user to input commands, load CSV files, display loaded submissions and reviewers, and trigger the Edmonds-Karp maximum flow algorithm for review assignment or risk analysis. Continues running until the user selects the exit option (0).

Note
Time complexity: O(1) for menu rendering and basic operations, but bounded by O(V * E²) when executing the assignment or risk analysis algorithms.
