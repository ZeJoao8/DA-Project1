Detailed Description

Utility class to load configuration data from a custom CSV file.

  • Supports reading Submissions, Reviewers, Parameters, and Control sets from predefined sections labeled with headers starting with '#'. Extracts data into ready-to-use C++ data structures.

◆ loadData()

bool DataLoader::loadData ( const std::string &  filename)

Loads and parses data from the specified setup CSV file.

  • Reads the file line by line, identifies the current section via '#' headers, splits the lines by commas, and delegates the creation of objects to the specific parsing helper functions.
  • Parameters
    filenamePath to the configuration CSV file.
    Returns
    true if successful, false if the file cannot be opened.
    Note
    Time complexity: O(N * L), where N is the number of lines in the file and L is the maximum line length.
