Graph< int > createGraphGeneral ( DataLoader & loader,
int mode )

Creates a flow network based on the provided data and assignment mode.

This function constructs a graph where:

  • SUPER_SOURCE connects to all reviewers with capacity 'maxReviewsPerReviewer'.
  • Each submission connects to SUPER_SINK with capacity 'minReviewsPerSubmission'.
  • Based on the mode (1, 2, or 3), edges are created between reviewers and submissions if their expertise matches.
    Parameters
    loaderReference to the DataLoader containing conference data.
    modeThe assignment mode (1: Primary, 2: Primary+Secondary Sub, 3: All matches).
    Returns
    A constructed flow graph.
    Complexity:\n O(R * S), where R is the number of reviewers and S is the number of submissions.
