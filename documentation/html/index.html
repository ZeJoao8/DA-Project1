Scientific Conference Organization Tool

Introduction

This project implements a system for organizing scientific conferences, focusing on the automatic assignment of reviewers to submissions.

Problem Description

Each submission requires a minimum number of reviews, and each reviewer has a limited capacity and a set of submissions they are able to review.

Approach

The problem is modeled as a flow network where:

  • A Source node connects to reviewers
  • Reviewers connect to submissions
  • Submissions connect to the Sink node

The Edmonds-Karp algorithm is used to compute the maximum flow, ensuring an optimal assignment of reviewers.

Features

  • Automatic reviewer assignment
  • Interactive mode (CLI)
  • Batch mode using CSV files
  • Risk analysis (detection of critical reviewers)
