Adds a directed flow edge and its corresponding reverse edge to the graph.

Creates a forward edge from src to dest with the given capacity, and a backward edge from dest to src with capacity 0. Both edges are linked via their reverse pointers to support residual graph operations.

Parameters
gThe flow graph.
srcInfo value of the source vertex.
destInfo value of the destination vertex.
capacityCapacity of the forward edge.
Note
Time complexity: O(V), where V is the number of vertices due to linear search performed during findVertex().

Augments flow along the path from s to t by f units.

Traces back from t to s using each vertex's recorded path edge. Forward edges have their flow increased by f; backward edges have it decreased.

Parameters
sPointer to the source vertex.
tPointer to the sink vertex.
fFlow amount to push (bottleneck value from findMinResidualAlongPath()).
Precondition
An augmenting path must have been found and its bottleneck computed.
Note
Time complexity: O(V), where V is the number of vertices on the path.

Computes the maximum flow from source to target using the Edmonds-Karp algorithm.

Repeatedly finds shortest augmenting paths (BFS) in the residual graph and augments flow along them until no augmenting path exists. All edge flows are reset to zero before execution begins.

Parameters
gPointer to the flow graph.
sourceInfo value of the source vertex.
targetInfo value of the sink vertex.
Returns
The maximum flow value from source to target.
Note
Time complexity: O(V * E²), where V is the number of vertices and E the number of edges.

Finds an augmenting path from s to t via BFS on the residual graph.

Traverses both forward edges (with remaining capacity) and backward edges (with positive flow). Each visited vertex records the edge through which it was reached, enabling path reconstruction.

Parameters
gPointer to the flow graph.
sPointer to the source vertex.
tPointer to the sink vertex.
Returns
true if an augmenting path to t was found; false otherwise.
Note
Time complexity: O(V + E), where V is the number of vertices and E the number of edges.

Vertex< int > * t )

Computes the minimum residual capacity (bottleneck) along the augmenting path.

Traces back from t to s using each vertex's recorded path edge. For forward edges the residual is weight - flow; for backward edges it is flow.

Parameters
sPointer to the source vertex.
tPointer to the sink vertex.
Returns
The bottleneck capacity along the path.
Precondition
An augmenting path from s to t must have been found by findAugmentingPath().
Note
Time complexity: O(V), where V is the number of vertices on the path.
