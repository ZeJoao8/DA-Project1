Detailed Description

Operations for review assignment and risk analysis.

Responsoble for the construction of the flow network, execution of the Edmonds-Karp maximum flow algorithm, result extraction, and risk analysis to solve the problem.

◆ createGraphGeneral()

Graph< int > createGraphGeneral ( DataLoader & loader,
int mode )

Constructs the flow network for the reviewer assignment problem.

Creates a super source connected to all reviewers (capacity = max reviews) and submissions connected to a super sink (capacity = min reviews). Edges between reviewers and submissions are added based on domain compatibility (mode).

Parameters
loaderThe DataLoader object containing parsed CSV data.
modeGenerateAssignments value (1 = Primary, 2 = Primary/Secondary, etc.).
Returns
The constructed flow graph ready for maximum flow computation.
Note
Time complexity: O(R * S), where R is the number of reviewers and S the number of submissions.

◆ executeRiskAnalysis()

void executeRiskAnalysis ( DataLoader & loader,
const std::string & outputFile = "" )

Performs risk analysis (M=1) by testing the system's robustness against reviewer absence.

Temporarily disables each reviewer (setting their capacity from the super source to 0) and recalculates the maximum flow. Identifies "critical" reviewers whose absence prevents the system from reaching the expected total flow.

Parameters
loaderThe DataLoader object populated with input data.
outputFileOptional custom path to append the risk analysis results.
Note
Time complexity: O(R * V * E²), where R is the number of reviewers, V is the number of vertices, and E the number of edges.

Extracts successful review assignments from the solved flow network.

Traverses the residual graph to find edges between reviewers and submissions that have positive flow, indicating a valid assignment match.

Parameters

loaderThe DataLoader object containing original entity data.
modeGenerateAssignments value to determine which domain caused the match.
Returns
A vector of Match structures representing the assignments.
Note
Time complexity: O(V + E), where V is the number of vertices and E the number of edges.

Identifies submissions that failed to reach the required minimum number of reviews.

Checks the edges connecting submissions to the super sink. If the flow is strictly less than the capacity (weight), the submission lacks the necessary reviewers.

Parameters
networkThe flow network after executing the Edmonds-Karp algorithm.
loaderThe DataLoader object containing original entity data.
maxFlowThe total maximum flow achieved in the network.
expectedFlowThe ideal total flow (Number of Submissions * Min Reviews).
Returns
A vector of Missing structures representing submissions lacking reviews.
Note
Time complexity: O(S + E), where S is the number of submissions and E the number of edges.
