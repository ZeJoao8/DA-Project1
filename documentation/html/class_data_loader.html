Detailed Description

Utility class to load configuration data from a custom CSV file.

Supports reading Submissions, Reviewers, Parameters, and Control sets from predefined sections labeled with headers starting with '#'. It properly removes inline comments started by '#'.

bool DataLoader::loadData ( const std::string & filename)

Loads and parses data from the specified setup CSV file.

Reads the entire CSV config file and populates internal structures.

Parameters
filenamePath to the configuration CSV file.
Returns
true if successful, false if the file cannot be opened.
Complexity:\n O(N*M) where N is lines and M is tokens per line.
Parameters
filenameThe name of the file in ../datasets/input/
Returns
True if successful.
Complexity:\n O(L * T) where L is the number of lines and T is the tokens per line.
